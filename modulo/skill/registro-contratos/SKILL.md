# Registro de contratos

El maestro original es solo lectura. Clasifica cada documento como nuevo, actualización, duplicado o rechazado. Los campos con confianza menor a 0.8 requieren revisión. Los otrosíes actualizan el contrato base y conservan historial. Los reportes alertan vencimientos <=60 días y pólizas pendientes.
